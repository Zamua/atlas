# Atlas

Learn by mastery. Each course is a map of small concepts: a short voiced explainer, then
practice problems until you have it, then spaced reviews so it sticks. Progress syncs between
devices with no sign-up, and the whole site works offline.

Try it: https://j2r87q39.hostthis.dev

## Courses

- **Deep Learning**: from linear algebra to transformers, language models and post-training.
- **Nix**: the language, the store, packages and flakes.

## Run

    npm install
    npm run dev
